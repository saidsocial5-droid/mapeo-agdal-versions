# Mapeo Agdal : versions

Ce dépôt contient **uniquement les fichiers d'installation (APK)** de Mapeo Agdal, l'application de surveillance de l'Agdal de l'APAC Aït Hcein O Hand (Association Forêt Modèle d'Ifrane, AFMI, projet FEM).

## Installer et recevoir les mises à jour

1. Installer **Obtainium** sur le téléphone Android (github.com/ImranR98/Obtainium ou F-Droid).
2. Dans Obtainium : **Ajouter une application**, puis l'adresse `https://github.com/saidsocial5-droid/mapeo-agdal-versions`.
3. Appuyer sur **Installer**. Obtainium installera ensuite chaque nouvelle version automatiquement (connexion internet nécessaire au moment de la vérification).

Chaque APK est signé avec la clé de l'AFMI : Android refuse toute mise à jour signée par quelqu'un d'autre.

# Mapeo Agdal : الإصدارات

يحتوي هذا المستودع **فقط على ملفات تثبيت (APK)** تطبيق Mapeo Agdal لمراقبة أكدال بالمنطقة المحمية التشاركية آيت حسين أوحند (جمعية الغابة النموذجية لإفران).

1. ثبّت تطبيق **Obtainium** على هاتف Android.
2. في Obtainium اختر **إضافة تطبيق** وأدخل العنوان `https://github.com/saidsocial5-droid/mapeo-agdal-versions`.
3. اضغط **تثبيت**. سيُحدِّث Obtainium التطبيق تلقائياً عند توفر إصدار جديد واتصال بالإنترنت.
